# 118.vn — Giao Đồ Ăn Nhanh

Website giao đồ ăn nhanh, học thiết kế từ Meituan.

## Tính năng
- Responsive mobile-first
- Đa ngôn ngữ: Tiếng Việt / English / 中文
- Chọn địa chỉ giao hàng + GPS
- 8 nhà hàng mẫu với menu đầy đủ
- Giỏ hàng, đặt hàng, theo dõi đơn real-time
- Thanh toán: QR Banking, MoMo, Thẻ, Tiền mặt

## Deploy
Vercel static hosting — tự động deploy khi push.

## Tech Stack
- HTML + CSS + Vanilla JavaScript
- Vercel Static Hosting
